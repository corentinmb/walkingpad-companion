Your walks, on your Mac.

This page describes the current app and this presentation website. You can inspect the implementation in the public repository.

Bluetooth and saved workouts

The app connects to your treadmill over Bluetooth and saves workout history locally in its macOS sandbox. Bluetooth permission is needed to discover and control the device.

Statistics server

While running, the app serves treadmill state and workout history on port 4934, and accepts treadmill commands. This existing API has no authentication and is not intended for public exposure. The Stats button opens the external walkingpad-stats.netlify.app viewer, which reads data from the running app. That viewer is a separate website.

Optional integrations

If you log in to HCGateway, workout data is uploaded to the hosted service at api.hcgateway.shuchir.dev and authentication tokens are stored in the macOS Keychain. If you supply an MQTT configuration, treadmill state is sent to your configured broker. The MQTT configuration file includes any credentials you provide. These services have their own handling of data.

This website

This static site includes no analytics scripts, cookies or external fonts. GitHub Pages hosts it and may process request information according to GitHub’s privacy statement. Links to GitHub and the external statistics viewer take you to separate services.
